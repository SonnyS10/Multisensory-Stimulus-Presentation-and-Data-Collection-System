# Quick Start - Adding Stimulus Images

## You currently have NO default images!

The application will run, but you **MUST** add images to use the system properly.

## Option 1: Add Images to Default Folders (Recommended)

### For Alcohol Stimuli:
1. Find or download alcohol-related images (beer, wine, liquor, etc.)
2. Place them in: `Default/Alcohol/`
3. Delete or rename the `PLACE_IMAGES_HERE.txt` file

### For Neutral Stimuli:
1. Find or download neutral images (water, juice, soft drinks, etc.)
2. Place them in: `Default/Neutral/`
3. Delete or rename the `PLACE_IMAGES_HERE.txt` file

## Option 2: Use Custom Folders

When you launch the main application (main.py):
1. Click "Browse" next to "Alcohol Images Folder"
2. Select a folder containing your alcohol images
3. Click "Browse" next to "Non-Alcohol Images Folder"
4. Select a folder containing your neutral images

## Image Requirements

- **Minimum**: At least 1 image per category (alcohol/neutral)
- **Recommended**: 10-15 images per category
- **Formats**: .jpg, .jpeg, .png, .bmp, .gif, .tiff, .webp
- **Resolution**: 800x600 pixels or higher

## Testing

After adding images, launch the GUI and check:
1. No warning messages about missing images
2. Stimulus Order Management shows your images
3. Images appear correctly in alcohol and neutral tests
